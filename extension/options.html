Tasks you add are written straight to your tasks repo on GitHub; the desktop app picks them up on its next Sync. Use a separate fine-grained personal access token scoped to only the tasks repo, with Contents: Read and write, so you can revoke it on its own.

The token is stored in Chrome's extension storage on this computer. Unlike the desktop app's token, it is not encrypted by the operating system, so anyone with access to your Chrome profile could read it.
